# ChartClip

ChartClip is a browser-first prototype for turning structured data into timeline-ready motion chart clips.

## Stack

- Vite
- Vue 3
- TypeScript
- ESLint
- PixiJS
- GSAP

## Scripts

- `npm run dev`
- `npm run build`
- `npm run preview`
- `npm run lint`
- `npm run lint:fix`
- `npm run typecheck`
